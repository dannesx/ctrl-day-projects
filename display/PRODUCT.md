# Editor OLED

## Platform
Web local para editar o OLED SSD1306 128×64 do projeto ESP32.

## Stack
HTML, CSS e JavaScript estáticos, conforme solicitado. Sem serviços externos.

## Uso confirmado
Editar LEDs individualmente, criar telas, salvar no navegador, exportar PNG e código Arduino. Incluir telas do jokenpo, conforme resposta do usuário. JSON editável permite intercâmbio com o assistente.

## Restrições
16 linhas amarelas no topo, 48 azuis abaixo; cada LED é binário. Exportações devem preservar coordenadas e resolução. Salvamento local deve comunicar falhas.
