# Sonar local

Interface Python/Pygame para o usuário visualizar ângulo e distância de um
HC-SR04 montado em motor de passo controlado por Arduino Uno via USB.
Referência visual explícita: imagem de radar semicircular fornecida na conversa.
Fluxo: ligar, estabelecer 90°, iniciar, observar obstáculos, pausar.
Sem sensor de posição: a orientação é estimada pelos passos comandados.
Modo de demonstração deve ser explicitamente identificado.
